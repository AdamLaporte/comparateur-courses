# Décisions

Une ligne par décision importante, la plus récente en bas. Toute modification d'un fichier partagé
(`app/main.py`, `app/config.py`, `app/db.py`, `app/contrats.py`, `app/sources/base.py`, `app/templates/base.html`)
est aussi notée ici.
