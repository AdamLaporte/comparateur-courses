# Localisation directe des magasins

- Agent Codex sur main, lots magasins et interface.
- Géocodage inverse des coordonnées lorsque la ville ou la rue manque dans les données. Les adresses déduites sont signalées comme proches.
- L’en-tête lien ouvre le plan et conserve la localisation visible. En l’absence de donnée, le code postal ou le repère reste disponible.
- Changements dans le géocodage, la route et le gabarit du comparatif, le style et le test de parcours.
