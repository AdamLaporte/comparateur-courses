# Lieux enregistrés et trajet optionnel

- Agent Codex sur `main`, lots interface, magasins et comptes.
- Création, modification et suppression de lieux par compte, avec coordonnées et mode favori.
- Panneau repliable pour choisir le départ et activer les informations de trajet. Rayon par mode ou valeur personnalisée.
- Fichiers modifiés dans les comptes, les magasins, les gabarits, le style, les tests et la documentation.
- Les estimations utilisent la distance à vol d’oiseau. La disponibilité d’un itinéraire ou d’un accès PMR demande des données supplémentaires.
